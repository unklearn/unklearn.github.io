# Scout Foundations: owner’s brief

Teach an agent runtime through a courier in one village. The lesson begins with
scripted movement, then adds tools, execution and feedback one at a
time. Use short public dialogue, never invented model reasoning. Let the reader
see exactly where the returned notice becomes input to the next evaluation.

The five steps and tools are declared in steps.ts. Edit the Markdown for prose,
stage instructions for interactions, and ../../mock.ts for supported deterministic
responses. These authoring files are not Scout’s system prompt.

A model helping author the lesson should read this brief, ../../catalogue.md, steps.ts
and the marked executable excerpts. `article.ts` registers this article’s title,
content directory, actions and recording compatibility. Generate ordinary TeachingStep source and
Markdown, review it in the browser, and keep experiments within the catalogue.
There is no runtime lesson compiler or automatic forwarding of this brief.
